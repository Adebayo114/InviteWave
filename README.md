# InviteWave – Event Management Web App

🔗 Live Demo: (https://www.invitewave.events/)  
💻 Tech Stack: React, JavaScript, CSS, Firebase, React Router

## Overview
InviteWave is a web application that allows users to create and manage events. The platform demonstrates dynamic form handling, responsive design, and structured component architecture.

## Features
- Event creation and management
- Form validation
- Responsive UI for mobile and desktop
- Client-side routing
- Firebase integration for backend services

## What I Learned
This project strengthened my skills in component architecture, state management, and integrating frontend applications with backend services.
